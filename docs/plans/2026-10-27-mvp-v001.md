# MVP v0.01 實作計畫

> 狀態：2026-10-27 封存。本文件為重新規劃前的既有文件，僅供查核既有資源與歷史版本；不代表新產品需求或繼續開發的授權。新規劃以 `docs/PRD.md` 的待確認提案為準。

> 歷史首版計畫（2026-10-27）；解析失敗與使用者確認機制由 [v0.02 計畫](2026-10-27-v002-import-dialogue.md) 接續，當前驗收見 [v0.02 release](../RELEASE-v0.02.md)。

> 執行方式：依已核准 PRD 連續實作，以 `subagent-driven-development` 分工獨立介面、由主程序整合資料與部署；不在工作段落間重複要求開始授權。

**Goal:** 完成私人 AI Studio、完整來源匯入、元素中央登錄、世界／視覺確認，以及英文網站發布和中英日翻譯校準。

**Architecture:** v0.01 採 React/Vite、TypeScript/Hono Worker、D1、R2 與 Queue。PRD 的 Python/PostgreSQL 是建議堆疊；本版為使用現有部署授權、減少單人營運服務數，採相同契約語意的 Zod runtime 與 D1 交易，原作不寫入程式。所有模型使用 Meta 原生 API，推理 `muse-spark-1.3`、影像 `muse-image-1.0`。私有測試原作保存於忽略目錄／private R2，公開只輸出審核後 DTO。

**Baseline:** 開始時僅 README/PRD，無應用與既有測試。工作分支 `feat/mvp-v001`。

> 2026-10-27 狀態：程式與 dev／production 已部署，實際驗證見 RELEASE-v0.01.md。以下為執行清單；未勾項目仍待 live 或作者驗收。瀏覽器身分按使用者本次指示採 FlyPig，不因測試 IP 改 lane。

# World Studio v0.07｜單一對話總監與幕後 Agents

狀態：作者已核准實作。這是目前產品與資料契約；驗證及外部連接狀態以 [Operations](OPERATIONS.md) 的實際查核結果為準。

## 1. 產品體驗

作者只面對一位世界創作總監。原稿匯入、閱讀、創作討論、設定確認、選圖、網站預覽、發布及營運，都在同一段持久化對話完成。介面保留世界／對話切換、訊息區、附件及輸入框；來源、記憶與用量按需展開。

作品提供創作錨點與不可改動的限制。未知地方、生命與相遇可以在作者核准的範圍內延伸；初始化不建立完整百科，也不逐句要求作者證實引文。相同調度及契約處理不同題材，不內建作品專名、年代、災變或生態。

首次閱讀後交付原著核心理解，以及五個面向的具體建議：

| 面向 | 需要形成的判斷 |
|---|---|
| 延伸尺度 | 哪些核心不可改動，哪些地方／生命／環境可衍生，哪些需要再次提案 |
| 探索行為 | 誰觀察、如何探索、看見哪些內容，風景／生態及相遇的比例 |
| 主線關係 | 旅程時間、原作人物使用範圍、劇情與劇透界線 |
| 視覺基準 | 實際參考圖、畫面語言、環境及生命外觀，經試稿確認 |
| 受眾感受 | 敘述聲音、閱讀感受、內容尺度與網站呈現方向 |

資訊充分就提出可用建議；只有會改變成品的歧義才追問。每個問題都說清楚要決定什麼、對成品的影響及建議答案。技術故障不能包裝成創作問答。

## 2. 總監與工作調度

總監讀取最新有效記憶及相關來源，判斷直接回答、修訂提案或啟動子任務。普通討論不重跑所有角色。子 Agent 提交候選；核准、資料提交、排程、重試、部署及預算均由程式控制。

| 角色 | 輸入 | 輸出 | 作者確認 |
|---|---|---|---|
| 世界創作總監 | 作者本輪意圖、來源、最新設定與工作狀態 | 自然語言回覆、創作方向提案或具體任務 | 原作核心及五面向的採用 |
| 閱讀協作 | 長篇章節、網站頁面、真實參考像素 | 重要線索、禁止事項、矛盾、來源定位；非劇情百科 | 僅無法從來源判斷的創作歧義 |
| 世界發展 | 核准方向、原作限制、既有元素 | 地方、生命、物件及關聯的候選；自主輪次可零新增 | 初始化候選須確認；後續限已授權範圍 |
| 探索策劃 | 世界、觀看方式、最近旅程 | 探索目的、相遇、小事件、狀態變化 | 示範內容於預覽中確認；自主輪次受既有授權控制 |
| 視覺導演 | 實際圖片、核准風格、元素外觀、探索計畫 | 構圖安排、Muse Image 影像 | 初始化實際試稿選圖 |
| 記錄編輯 | 旅程、已產生影像、名稱及聲音 | 公開英文介紹、日誌與圖說 | 首次網站預覽及發布；後續依範圍 |
| 忠實度與一致性審核 | 候選、原作原文、核准界線、既有紀錄 | 通過、具體修正要求或需作者裁定的衝突 | 只有超出授權或重大歧義才詢問 |
| 網站製作 | 抽象視覺設計基準、公開內容結構 | 每世界獨立 HTML／CSS、導覽與版面候選 | 採用設計與發布分開確認 |
| 多語編輯 | 審核後公開文字、穩定名稱及翻譯原則 | en／zh-Hant／ja 內容及定義 | 翻譯疑義以對話校準；完整審核才公開 |

角色使用 Meta `muse-spark-1.3`；影像使用 `muse-image-1.0`。調度採部署端持久化任務與工具權限，不依賴另一個模型供應商的 Agent 服務。模型容量、來源取得與輸出限制以實際可用值為準，不用上下文上限承諾理解正確率。

每項任務綁定世界版本、取消世代、上游成果、執行識別與租約。完成成果先落 R2 收據再交接；語意／結構錯誤不能當有效快取。無效回應仍記錄用量。可修正問題回原角色，暫時性故障最多自動重試兩次；超限保存成果並在對話顯示可操作的重試。

作者取消後不再派後續工作。新的計費呼叫前及採用結果前重查租約／取消狀態；已送出的供應商請求可能無法撤回，遲到結果不能採用或發布。

## 3. 原稿與整站閱讀

作者不必摘要、切章或先寫設定表。全文在可用上下文與單次工作預算內時直接閱讀；超出時按章節／段落續讀，每批保存閱讀筆記與原文定位，再由總監合併。重要禁止事項及核心判斷回查原文，審核者亦能取得原始依據。後續回合沿用核准記憶與相關原文，不讓每個角色重讀全書。

來源支援貼文、TXT／Markdown、DOCX、文字型 PDF、公開網頁及可讀取的 Google 文件。原始檔、文字、圖片、版本與內容雜湊私人保存。掃描 PDF 沒有文字層時明確回報需要可讀文字，不假稱完成 OCR。

整站限同 origin：去除導覽／重複正文，保存有效頁、圖片、缺頁及讀取狀態。每批最多取得一百頁，保存游標及溢出的待讀清單；更大網站接續，不丟剩餘連結。外站連結不無限追蹤。衝突仍無法從來源判斷才請作者指定。

圖片使用實際像素，單張 PNG／JPEG／WebP 上限 5 MiB，每批六張。原檔分別上傳，對話只傳安全儲存識別，避免多張 Base64 膨脹請求。DOCX 擷取內嵌圖片；PDF 渲染含圖頁作參考，皆保留全文文字，每批擷取最多六張並告知未納入範圍。Google 文件目前文字連線不含完整配圖時明示，作者可補傳代表圖。參考閱讀每輪最多兩張，逐批涵蓋已納入的圖片並保存觀察結果。

驗收含十萬中文字原稿、一百頁有效內容網站、晚段限制、超過千頁的游標續讀及六張各 5 MiB 圖片；更大輸入以接續工作處理。單文件目前 25 MiB、單次文字四百萬字元，超過時如實說明，不靜默截斷。

## 4. 中央世界記憶與資料契約

聊天保存討論，資料庫保存有效記憶，兩者不互相代替。草稿、核准設定與公開快照各自獨立；舊聊天不能覆蓋新裁定。

| 資料集合 | 主要欄位／責任 |
|---|---|
| conversations／events／turns | 獨立世界對話、單調事件序號、作者訊息識別、輸入雜湊、取消世代 |
| sources／assets／crawls | 原檔、正文、圖片像素、來源網址與定位、內容雜湊、續讀進度 |
| proposals／approvals／memory | 類型、對應版本、候選內容雜湊、作者訊息證據、不可變核准快照 |
| world.elements | 穩定 ID、種類、中英日名稱、特色、外觀、關聯、來源類別 |
| tasks／outbox／checkpoints | 角色、依賴、版本、租約、取消、重試、持久化派送及有效成果重用 |
| usage／quota_reservations／audit | 成功／不確定用量、原子呼叫預留、實際操作稽核 |
| sites／publications | 獨立版型、程式雜湊、候選分支／PR／commit、私人預覽、公開內容快照及有效版本 |
| operation_runs／automation_wakeups／journey_records | 核准政策、唯一輪次、事件驅動排程、旅程與後續影響 |

執行契約定義於 `src/shared/conversation.ts`，資料表由 migrations 0006／0007 新增；舊資料表仍保留原檔與歷史發布，不自動遷移核准或重跑。

元素來源類別分 `source`、`inference`、`extension`、`author`，只在私人記憶保存。元素 ID 不因翻譯改變，後續沿用已採用名稱及外觀。新來源、方向、世界或視覺修改使相關網站候選／自主政策失效，但不刪除既有公開版本。修改只重做受影響的成果。

## 5. 對話核准與發布

提案具版本及內容雜湊，作者不需操作版本欄位。只有真正作者訊息可授權，原作、網頁文字、模型輸出及子任務的同意字樣不具授權。

| 作者說法 | 行為 |
|---|---|
| 城市再有生活感一點 | 產生修改草稿，未核准 |
| 採用剛才的方向／採用指定提案 | 核准明確指向的候選 |
| 第二張畫風對了 | 採用同一視覺提案的第二張試稿 |
| 採用這份網站設計 | 核准設計，尚未公開 |
| 發布網站 | 核對指定已核准候選與目前內容，執行受控發布 |
| 開始每天更新 | 先提出頻率、範圍與作者指定配額，另行確認 |

「可以／對／好」只在前一則是單一提案的明確核准詢問時成立。多候選或假設／否定／改稿語句不能誤核准。設定、視覺、設計、公開發布及自主政策是不同授權。

網站 Agent 自行設計獨立版面，不選用固定作品模板。v0.07 產生隔離的 HTML／CSS 入口，內容由公開快照動態填入；互動限導覽、語系與原生展開，不執行生成腳本。設計程式輸入只含嚴格列舉的抽象視覺基準與內容結構，原作、私人專名與作者指示不進公開 repository。

程式僅可改 `sites/<site-id>/` 的版型／樣式／manifest 及受控版號檔案。檢查拒絕腳本、外站請求、事件屬性、任意文案、CSS 字串與隱藏內容；導覽及 ARIA 有三語固定對應。故事文字、圖說、專名與介紹只來自審核後公開內容契約。

發布流程：私人預覽 → GitHub 候選 → 無憑證品質／安全檢查 → 可信服務回報預覽完成 → 作者發布 → 受控服務合併 → GitHub 自動部署 dev／正式 → 三語 HTML、內容雜湊及影像讀回 → 切換有效快照。正式合併僅 production 執行；dev 提供預覽及驗證。

每次正式發布序列執行，避免兩個世界同時覆寫主分支版本。主分支有更新時保留原版型、重設正確版號並重新驗證，不直接發布失效候選。部署失敗回報同一對話、釋放發布鎖並保留原站；再次明確發布可接續失敗部署或重新讀回，不用空 commit 喚醒 CI。

公開內容採白名單 DTO；原稿、來源依據、補全標記、作者裁定、提示詞及內部執行資訊不進公開 API／HTML／SEO／ARIA／替代文字。公開資產逐張驗證歸屬及存在性。公開網址只有完成實際讀回才回報成功。

## 6. 自主運行

首次發布後仍停用。作者另外指定頻率、創作範圍及呼叫次數上限，確認政策後才啟動；未指定上限不啟動。v0.07 以供應商呼叫次數作硬上限，尚不承諾依即時價格換算的金額預算。用量及不確定呼叫均計入，達上限停止新生成，不自動加額。

每輪：世界必要增量 → 審核 → 探索策劃 → 審核 → 影像 → 審核 → 英文編輯 → 審核 → 中英日 → 審核 → 公開讀回與切換 → 旅程／用量／audit 回寫。既有元素保留，新元素限核准範圍；越界內容留私人提案，不公開。

Cloudflare Workflows 在指定時間喚醒 Queue，一輪完成後才安排下一輪；沒有分鐘級輪詢。停止／取消／修改核准範圍後，舊喚醒不能恢復運行。同一世界只允許一個有效輪次；派送失敗可由持久化 outbox 或每日低頻 recovery 補送。

## 7. API 與介面

- `POST /api/studio/conversations` 建立對話，`GET /:id` 取得一致 snapshot。
- `POST /:id/files` 私人原檔上傳，`POST /:id/turns` 先保存作者輸入及 outbox，再回 202；`clientMessageId` 原子去重。
- `GET /:id/events?after=` 重播，`?before=` 載入更早對話；snapshot 保留最新一千則，舊訊息仍在資料庫。
- `GET /:id/stream` SSE 以事件 ID 接續，`POST /:id/cancel` 停止後續工作。
- `/studio-preview/:site/:locale` 僅登入作者可讀；`/api/studio/assets/:id` 私人素材。
- `/api/public/studio/:locale/:slug` 與 `/:locale/worlds/:slug` 只讀有效公開快照。
- `/api/studio/deployments` 接收受保護的 CI 成功／失敗回報，按 delivery ID 去重。

訊息區直接呈現提案、選圖、私人預覽、執行進度與正式網址。可選的採用按鈕使用與聊天相同的命令和核准服務。工作期間仍可補充，重新開啟能恢復，不重送已執行工作。

## 8. 驗收與後續範圍

必驗：兩篇不同題材使用相同引擎；十萬字及百頁網站；晚段禁止事項；超過十二輪的記憶與重新開啟；明確核准與錯誤指涉；每張 5 MiB；取消、格式失敗、派送失敗、資產缺失、部署失敗恢復；獨立版型／路由；三語文字及公開資訊隔離；三輪自主探索、預算、audit 及暫停。

單元／SQLite 整合、實際瀏覽器、供應商連線與正式環境驗證分別記錄，不能用 mock 成功宣稱 GitHub 或 Cloudflare 的真實發布成功。GitHub App 未連接時提供可用私人預覽及明確連接方式，不偽造 PR、部署或網址。

每週明信片、訂閱寄送及美術集為後續階段，不在 v0.07 建立寄送排程。新增郵件流程時另依部署端事件驅動、退訂篩選、持久化 audit 與永久冪等實作。

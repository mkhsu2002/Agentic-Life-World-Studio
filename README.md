# Agentic Life World Studio

把原作交給 AI 世界創作總監，透過同一段對話，建立一個能持續出版影像與旅行見聞的世界網站。

## 使用方式

上傳完整小說、Word、PDF、參考圖片，或提供故事宇宙網站網址。總監閱讀後提出核心理解與創作方向；作者直接用對話調整設定、挑選視覺試稿、查看網站預覽及發布，不必填設定表或切換審核頁面。

原著提供核心錨點與限制。新的地方、生命及相遇，依作者核准的範圍發展；每個世界有獨立設計的網站版型。首次發布只包含已確認內容，自主更新保持停用，作者另外確認頻率、創作範圍與用量上限後才會啟動。

- **私人 Studio：**持久化對話、附件、進度、修改提案、視覺校準及私人網站預覽。
- **中央世界記憶：**保存來源、核准方向、穩定元素 ID、多語名稱、外觀及歷次探索，支援跨回合延續。
- **世界網站：**預設英文；繁體中文與日文通過內容檢查後公開，持續探索成果回報同一段對話。

## 開發與部署

需要 Node.js 24 以上。

```sh
npm ci
npm run check
npm run dev
```

完整產品規格見 [PRD](docs/PRD.md)，API、授權設定及部署操作見 [Operations](docs/OPERATIONS.md)。推理與影像憑證只留在部署端安全儲存；網站發布使用僅授權此 repository 的 GitHub App。

程式碼經 GitHub 驗證後自動部署 Cloudflare，dev 與正式環境同步檢查資料契約。每批程式碼版本增加 0.01，純文件編修不升版，也不觸發正式部署。

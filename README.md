# Agentic Life World Studio

讓作者把原作建立成一個持續出版探索影像與旅行見聞的世界網站。

作者在私人 Studio 匯入文字、Word、PDF 或網頁與參考圖片；AI 先整理世界的創作方向，作者確認核心設定、延伸範圍與實際視覺試稿後，才建立公開網站。網站預設英文，逐步支援繁體中文與日文。

## 產品構成

- **AI Studio：**閱讀原作、提出設定草稿與具體建議，透過對話完成必要裁定及視覺校準。
- **中央世界資料庫：**保存核心設定、核准範圍、元素特色、多語名稱與內容版本，供後續創作保持一致。
- **公開世界網站：**以影像、旅行見聞、領域與生命的發現呈現世界；持續出版並回報 Studio。

## 設計原則

AI 先完成可用草稿，只有確實需要作者決定的問題才請作者回答。忠於原作的核心設定；補全範圍與視覺方向必須經作者核准才能用於出版。技術故障由系統處理，不能變成含糊的作者問答。所有世界設定由輸入推導，不綁定特定作品或類型。

## 規劃與開發

[產品規劃提案](docs/PRD.md) 定義成品、Studio 操作、資料架構、Agent 分工與分階段驗收。目前等待作者確認提案；確認後才進入開發。

程式碼發布一律經 GitHub 觸發 Cloudflare 自動部署，dev 與正式環境同步驗證。每批程式碼變更依既有版號增加 0.01；純文件編修不升版。模型憑證僅保存於安全儲存與部署端 secret。
